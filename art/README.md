# Графика

Графика игры собрана из бесплатных наборов с лицензией CC0 (можно использовать без ограничений, указание авторов не обязательно, но мы их указываем). Файлы лежат в `game/assets/`.

- Размер тайла: 16×16 пикселей
- Палитра: палитра наборов Kenney

## Наборы

| Набор | Автор | Лицензия | Папка | Что берём |
|---|---|---|---|---|
| Tiny Dungeon 1.0 | Kenney (www.kenney.nl) | CC0 1.0 | `game/assets/tiny-dungeon/` | замок, двери, предметы, персонажи |
| Tiny Town | Kenney (www.kenney.nl) | CC0 1.0 | `game/assets/tiny-town/` | деревня, таверна, лес |
| Tiny Farm 1.0 | Kenney (www.kenney.nl) | CC0 1.0 | `game/assets/tiny-farm/` | жители деревни, товары, бочки, ящики, урожай |
| Tiny Creatures | Clint Bellanger (clintbellanger.net) | CC0 1.0 | `game/assets/tiny-creatures/` | дополнительные персонажи |

## Персонажи

Номер тайла считается слева направо, сверху вниз, начиная с 0; в листе 12 тайлов в строке.

- Таненбум — Tiny Dungeon, тайл 84 (волшебник в фиолетовой шляпе)
- Торвальд — Tiny Dungeon, тайл 85 (молодой герой рядом с волшебником)

В панели диалогов вместо портретов показывается тайл говорящего персонажа.
