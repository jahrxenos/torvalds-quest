# Torvalds Quest

Обучающая пиксельная игра-квест для детей 8–12 лет. Маленький Торвальдс путешествует по Королевству Линукс: комнаты замка — это каталоги, предметы — файлы, а чтобы пройти дальше, нужно отдавать команды в терминале.

Проект по дисциплине «Проектный практикум», направление 09.03.03 «Прикладная информатика», УрФУ, осень 2026. Тема №13 «Создание обучающей игры для детей на тему программирования „CodeQuest“».

## Идея уровней

| Уровень | Чему учит | Команды |
|---|---|---|
| 1 | Последовательность действий | `ls`, `cd`, `pwd` |
| 2 | Чтение данных | `cat` |
| 3 | Работа с объектами | `mv`, `cp` |
| 4 | Права доступа | `chmod` |
| 5 | Цикл и условие | мини-скрипт |

## Стек

- Движок: [Godot 4](https://godotengine.org/) (GDScript)
- Графика: пиксель-арт
- Сборки: Windows (.exe) и HTML5 (GitHub Pages)

## Структура репозитория

```
game/   — проект Godot
art/    — исходники пиксельной графики
docs/   — пояснительная записка, дизайн-документ, материалы тестирования
```
